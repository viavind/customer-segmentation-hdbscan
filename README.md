# Customer Segmentation using HDBSCAN

A customer segmentation project using feature engineering, PCA, and HDBSCAN clustering to identify customer groups based on demographic, behavioral, and financial characteristics.

## Objective

The project aims to:
- Identify customer segments based on their characteristics and behavior
- Understand customer profiles and engagement
- Identify high-value customers and potential upselling opportunities

## Methodology

1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Feature Selection
5. Exploratory Data Analysis
6. Standardization using StandardScaler
7. Dimensionality Reduction using PCA
8. HDBSCAN Clustering
9. Parameter Tuning
10. Cluster Evaluation
11. Customer Profiling

## Feature Engineering

Several features were created to represent customer characteristics, including:
- Income Stability Score
- Behavioral Rank
- Tenure Days
- Interaction Score
- Product Rank
- Monetary
- Interest Gap
- Protection Breadth

## Results

The HDBSCAN model produced **5 customer segments** with a silhouette score of approximately **0.86**.

The resulting segments were interpreted based on their demographic, financial, behavioral, and engagement characteristics.
